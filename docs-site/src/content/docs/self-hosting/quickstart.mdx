**You need:** Docker Engine with the Compose v2 plugin (`docker compose version` prints
`2.x`; the older standalone `docker-compose` is not supported), `curl`, and a Linux or macOS
host — the stack runs as your own user id (`id -u` / `id -g`), which Docker Desktop on
Windows/WSL also provides.

<Steps>

1. **Get the compose file**

   ```bash
   curl -fsSL https://raw.githubusercontent.com/Strandgaard96/mc-gamertime/main/docker-compose.yml -o docker-compose.yml
   ```

   No clone needed — this one file is the whole self-host setup.

2. **Set your admin credentials**

   Create a file named `.env` next to `docker-compose.yml` containing:

   ```bash
   ADMIN_USERNAME=admin
   ADMIN_PASSWORD=<your-password>
   ```

   Use at least 12 characters — the first-boot bootstrap does not check, but every later
   password change does. Compose auto-loads `.env` from the same directory. The first boot
   creates this admin account; afterwards the variables are ignored, so an existing
   password is never overwritten. Once you have logged in, delete both lines again so the
   password isn't left on disk in plain text.

   <Aside type="caution">
   Don't skip this. Until an admin account exists, every request — the login page included —
   returns `503 {"detail": "Service unavailable"}`. Set both here, or create the account by
   hand as shown in the next step. Setting only one of the two is a startup error.
   </Aside>

3. **Start the stack**

   ```bash
   docker compose up -d
   ```

   Pulls the pre-built image from GHCR and creates the SQLite database and storage directory under `./config/app/` on first run. Wait a few seconds for the `mc-gamertime` container to become healthy.

   Image tags: `latest` and `X.Y.Z` follow [releases](https://github.com/Strandgaard96/mc-gamertime/releases); `main` is the edge build from every commit. Pin `image: ghcr.io/strandgaard96/mc-gamertime:X.Y.Z` in `docker-compose.yml` if you want to control when you upgrade.

   <Aside type="tip">
   To create accounts by hand — the first one if you skipped step 2, or more later:

   ```bash
   docker compose exec mc-gamertime python3 scripts/create-user.py \
     --username alice --display-name "Alice" --role admin --password <your-password>
   ```

   Run it with no arguments and it prompts for each value (needs a real terminal, so
   `docker compose exec` works but `exec -T` does not). Takes effect on the next request; no
   restart needed.
   </Aside>

4. **Open the app**

   Navigate to `http://localhost:4263` and log in.

   That works on the host itself only: the port is bound to `127.0.0.1` by default. To open
   it from a phone or another machine on your LAN, add `APP_BIND=0.0.0.0` to `.env` and run
   `docker compose up -d` again — see
   [Configuration → Host port and bind address](/self-hosting/configuration/#host-port-and-bind-address)
   for what that exposes.

</Steps>

<Aside type="tip">
**No Compose?** The image is self-hosted by default — SQLite, local file storage, no cloud
account — so a bare `docker run` works too:

```bash
mkdir -p config/app
docker run -d -p 127.0.0.1:4263:4263 --user "$(id -u):$(id -g)" \
  -v "$(pwd)/config/app:/data" \
  -e ADMIN_USERNAME=admin -e ADMIN_PASSWORD=<your-password> \
  ghcr.io/strandgaard96/mc-gamertime
```

Create the directory first and run as your own user: Docker creates a missing bind-mount
directory owned by `root`, and the image runs unprivileged, so without those two lines the
container exits with `cannot create /data/.jwt_secret: Permission denied`. Mount `/data` as
shown, or the database and generated JWT secret vanish with the container.
</Aside>

<Aside type="tip">
**Want to build from source instead?** Clone the repo and build locally:

```bash
git clone https://github.com/Strandgaard96/mc-gamertime && cd mc-gamertime
docker build -t mc-gamertime-local .
```

Then point `image:` in your `docker-compose.yml` at `mc-gamertime-local` before `docker compose up -d`.
</Aside>

## What's running

| Container | Role | Port (internal) |
|---|---|---|
| `mc-gamertime` | FastAPI + React frontend, embedded SQLite, local filesystem storage | 4263 |

`mc-gamertime` is exposed at `127.0.0.1:4263` on the host (loopback only unless you set `APP_BIND`).
